## Findings

- Real Whisper works end to end through our core: 6/8 exact, numbers become digits (desired).
- Warm latency is flat ~0.72 s for 3.5–4.3 s clips: the full 30 s encoder window dominates, so B3 (`audio_ctx` scaled to clip length) is the obvious speed lever.
- Cold first call 12.8 s (load + Metal compile): B1 must preload/warm the engine, never load on the first fn press.
- Mixed HU-EN tech words fail ("branchet" → "Branhet", "build" → "bujild"): D1 vocabulary hints target exactly this.

## Reproduce

```bash
mkdir -p bench/audio/e2e && cp bench/prompts/e2e.tsv bench/audio/e2e/prompts.tsv && cd bench/audio/e2e
while IFS=$'\t' read id lang text; do v="Tünde"; [ "$lang" = en ] && v="Eddy (English (US))"
  say -v "$v" -o $id.aiff "$text" && afconvert -f WAVE -d LEI16@16000 -c 1 $id.aiff $id.wav && rm $id.aiff; done < prompts.tsv
cd - && (cd core && cargo build -j 4 --release -p pusmogo-mcp --features whisper)
PUSMOGO_MODEL="$HOME/Library/Application Support/Pusmogo/models/ggml-large-v3-turbo-q5_0.bin" \
  python3 -I scripts/e2e.py core/target/release/pusmogo-mcp bench/audio/e2e/prompts.tsv 2>/dev/null
```
