# FLEURS EN 01: real English speech, turbo vs large-v3 (2026-11-08)

First English run on real speech: 100 clips from the English (`en_us`) **test** split of [FLEURS](https://huggingface.co/datasets/google/fleurs) (Google, CC-BY-4.0), one recording per sentence, the first 100 sentences in file order. Fetched with `scripts/fetch-fleurs.py --lang en` into `bench/audio/fleurs-en/` (git-ignored; never commit it). Read speech by many speakers, 9.7 s per clip on average (4.4–29.3 s), news and travel-guide style with foreign names. Apple M5 Pro, `pusmogo-bench --features whisper`, engine + cleanup, warm engine, both models q5_0, run one after the other on the same machine. The reference and output columns quote FLEURS transcripts (CC-BY-4.0). Hungarian counterpart: [fleurs-01](fleurs-01.md) (dev split, so the two are not directly comparable).

**Re-scored 2026-11-08** after the normaliser learned English ordinals ("eleventh" = "11th", "twenty-first" = "21st") and British/American spellings ("organised" = "organized", "colour" = "color", "-isation" = "-ization"); same clips, fresh runs: **turbo 5.9 % WER** (joined 5.3, CER 2.6, p50 0.65 s, exact 45/100), **large-v3 4.8 % WER** (joined 3.9, CER 2.1, p50 0.94 s, exact 47/100). The gap between the models is unchanged (1.1 points); finding 2 below now covers only ranges ("25 to 30" vs "25-30") and hyphenated "one-hundred", which the normaliser still does not join.

## Findings

1. **English is already good with turbo: WER 6.1 %, CER 2.8 %**, against 17.5 % WER for Hungarian on FLEURS. large-v3 cuts it to 5.0 % (−1.1 points, about 18 % fewer word errors: 109 vs 133 of 2183 words) at +0.35 s p50 (0.65 → 1.00 s) and 2.5× the memory. For English the gain is small; keeping turbo as the English default (D1) is supported by these numbers.
2. **Part of the remaining WER is scoring, not hearing.** Spelled ordinals in the reference against digits in the output count as errors ("eleventh" → "11th", "sixteenth" → "16th"; the normaliser maps English cardinals but not ordinals), so do British vs American spellings ("organised" → "organized", "hospitalised" → "hospitalized") and ranges ("25 to 30 year" → "25-30 years"). Both models lose the same points here, so the comparison holds, but the absolute numbers are a little pessimistic.
3. **Foreign names dominate the worst clips** for both models ("Oldrich Jelinek" → "Uldrich Delenic" / "Aldrich Dilenic", "Chandra Shekhar Solanki" → "Shauna Shankar Solansky", "Wong Kan Seng" → "Wang Kang Sang"), as in Hungarian. The personal dictionary is the fix for names that matter to a user.
4. **One turbo-only slip with symbols:** "~500 Congolese Francs" → "$500. It can go these francs"; large-v3 gets that clip right apart from the name. No inventions on any clip (no "Thank you", no credits) for either model.
5. **Latency stays flat with length** (RTF 0.067 turbo, 0.103 large-v3); the fixed 30 s encoder window dominates, as in fleurs-01.
